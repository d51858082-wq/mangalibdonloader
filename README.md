# Lib Downloader (MangaLib, SlashLib, HentaiLib)
Расширение для Chrome, Edge, Brave, Opera и Яндекс Браузера (любой Chromium с поддержкой Manifest V3). Сохраняет выбранные главы с MangaLib, SlashLib и HentaiLib в CBZ и PDF — CBZ открывают Komga, CDisplayEx, Tachiyomi/Mihon, YACReader и большинство читалок.
## Установка
1. Распакуйте архив в постоянную папку (после установки её нельзя удалять).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Яндексе — `browser://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `mangalib-downloader`.
## Использован
1. Откройте страницу тайтла или любой главы на MangaLib, SlashLib или HentaiLib.
2. Нажмите на иконку расширения — откроется вкладка загрузчика со ссылкой из текущей страницы.
3. Отметьте главы (Shift + клик — диапазон, чекбокс у тома — весь том). Если у глав несколько переводов, выберите нужный.
4. Выберите формат: CBZ, PDF или CBZ + PDF.
5. Нажмите «Скачать». Файлы появятся в папке загрузок: `<сайт>/<название>/<название> - т01 гл0001.cbz` или `.pdf` (например, `HentaiLib/…`).
При первом скачивании браузер может спросить разрешение на доступ к серверу картинок — это нужно, чтобы расширение могло их загрузить.
Не закрывайте вкладку загрузчика, пока идёт скачивание.
## Ограничения
- Сайт определяется по ссылке. Все три работают через один и тот же API, различается только заголовок `Site-Id`: расширение читает его со страницы сайта, а если не выходит — берёт запасные значения (MangaLib 1, SlashLib 2, HentaiLib 4) из `lib.js`.
- Скачиваются только общедоступные главы. Платные, скрытые и 18+ главы, которые требуют входа, не поддерживаются — по ним будет ошибка «Доступ закрыт».
- Сайт может ограничивать частоту запросов; расширение сам замедляется и повторяет запросы, но на очень больших тайтлах разумно качать порциями.
## Если что-то не работает
Сайт использует неофициальный API, и его адреса могут меняться. Что проверить:
- Откройте DevTools → Network на странице чтения главы (нужного сайта) и найдите запрос `.../chapter?number=…&volume=…` — в ответе должен быть массив `pages`. Если адрес API другой, поправьте `API` в начале `app.js`; если другой `Site-Id` — значение в `SITES` в `lib.js`.
- Если главы находятся, но картинки не скачиваются, посмотрите, с какого домена они грузятся на странице чтения, и добавьте его в `FALLBACK_IMAGE_SERVERS` в `app.js`.
- Ошибки видны в консоли страницы загрузчика (F12 на вкладке расширения).
Используйте для личного чтения офлайн и учитывайте правила сайта и права авторов.
## PDF
PDF создаётся локально в браузере после загрузки страниц главы. JPEG-страницы помещаются в PDF без повторного кодирования; PNG/WebP/AVIF и другие поддерживаемые браузером форматы преобразуются в JPEG. Обработка выполняется последовательно, чтобы уменьшить пиковое потребление памяти на больших главах.
Для HentaiLib используется `Site-Id: 3`. Запросы API и, при необходимости, изображения выполняются из контекста активной страницы HentaiLib через `activeTab`/`scripting`, чтобы браузер использовал текущую авторизованную сессию.
## HentaiLib: извлечение изображений со страницы
На странице чтения HentaiLib доступна кнопка «Забрать изображения». Расширение прокручивает ридер для запуска lazy-load, собирает текущие `img/src/srcset` и уже загруженные image-ресурсы, затем повторно получает их в контексте страницы с текущей сессией браузера и сохраняет в CBZ/PDF. Это предназначено для изображений, которые обычный браузер уже может просматривать; DRM/шифрование не обходятся.
При запуске с сайта расширение сохраняет ID исходной вкладки. Запросы HentaiLib и захват изображений выполняются именно в этой вкладке, а не во вкладке интерфейса расширения. Это важно для cookies, авторизации и CORS.
